## Prompt

Character design turnaround sheet for a 3D pixel-art story game set in a fantasy city inspired by Banaras. One character shown at the same scale in four full-body views side by side — front, three-quarter, side profile and back — plus a small head close-up and a row of six colour swatches along the bottom, on a plain flat warm-grey background. Stylised proportions about six heads tall with a clear, readable silhouette, designed so it can be built as a low-poly 3D model. Crisp pixel art with soft warm key light, consistent in style with the attached character lineup. No text, no labels, no watermark. The character: a wiry boatman (manjhi) in a white vest and rolled-up dhoti, a checked red gamchha tied as a headband, holding a long wooden oar.
